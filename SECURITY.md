
# Security Policy

## Supported versions

Security updates are applied to the **latest** release only. Please make sure
you are always running the most recent version from the
[GitHub Releases](https://github.com/portapps/vscodium-portable/releases) page.

## Reporting a vulnerability

We take security seriously. If you discover a security vulnerability in
VSCodium Portable, please **do not** open a public issue.

Instead, report it privately through one of the following channels:

* Open a **private security advisory** on GitHub:
  https://github.com/portapps/vscodium-portable/security/advisories/new
* Send an email to the maintainers using the contact details available on the
  GitHub profile.

Please include the following information in your report:

* Affected version(s) and release number.
* A description of the vulnerability and its impact.
* Steps to reproduce (or a minimal proof-of-concept).
* Any suggested mitigation if known.

### What to expect

* We will acknowledge your report within **5 business days**.
* We will keep you informed about the progress of a fix.
* Once a fix is released, we will credit you in the release notes if you wish.

## Scope

The launcher executable and build pipeline of this repository are in scope.
Security issues in **VSCodium** itself should be reported to the
[VSCodium project](https://github.com/VSCodium/vscodium/security).
